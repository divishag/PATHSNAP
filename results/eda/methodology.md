# EDA methodology

Raw source files were inspected without modification. Row indices remain original arc/node IDs. Malformed rows are counted as missing values. Blank lines are counted separately. Coordinates use longitude then latitude. Distances use the haversine formula with mean Earth radius 6,371,008.8 m; speed and distance totals use only adjacent valid points with positive time intervals. Observed distance is not road distance; apparent speed includes GPS noise. Degree axes in trajectory plots are for display only. Road connections are inspected as directed arcs; duplicate arcs collapse only in connectivity calculations. Reference routes are sequences of arcs; no pointwise labels or model performance are inferred here. Training and student-test outputs are identified separately. No evaluator data was inspected.
